# InkNote

本地笔记 + 密码管理桌面应用（Electron，数据全部加密存储在本机）。

## 下载

从 [GitHub Releases](https://github.com/SeleneDrift/inknote/releases) 下载：

- `InkNote-<版本>-setup.exe` —— 安装版
- `InkNote-<版本>-portable.exe` —— 免安装便携版
- `InkNote-<版本>.appx` —— Windows Store 包（未签名，仅限侧载）

## 使用

```bash
npm start        # 启动应用
npm run dist     # 打包为 Windows 安装包（输出在 release/）
npm run verify   # 端到端回归（需先带调试端口启动，见下）
```

打包产物（`npm run dist`，首次运行会联网下载 Electron 与 NSIS 工具链）：

- `InkNote-<版本>-setup.exe` —— NSIS 向导式安装器（多语言，可选安装目录）
- `InkNote-<版本>-portable.exe` —— 免安装单文件版，适合 U 盘携带/临时使用

图标源文件在 `build/icon.svg`（mac 风格圆角、蓝底白圈对勾，圆角外透明），改完后 `npm run icon` 重新生成 `build/icon.ico`（自带透明圆角校验）再打包。**exe 未做代码签名**：本机直接运行没问题，分发给别人时 Windows SmartScreen 可能弹出"已保护你的电脑"警告（更多信息 → 仍要运行）；要消除警告需要购买代码签名证书并在 `build.win` 中配置 `certificateFile`。

端到端回归需先以调试端口启动应用：

```bash
node_modules/electron/dist/electron.exe --remote-debugging-port=9222 .
node scripts/verify.js
```

首次启动会要求设置主密码——所有数据（笔记 + 密码库）都用它加密（AES-256-GCM），**忘记主密码无法找回**。建议同时设置 1-3 个密保问题：忘记主密码时答对任一问题即可重置主密码，数据不丢失。密保问题也可以解锁后在侧栏「密保问题」中随时增删（保存需确认主密码）。

## 功能

- **笔记**：Markdown 编辑/预览、标签、全文搜索、自动保存，解锁后自动解密
- **密码库**：分组管理、一键复制、显示/隐藏、随机强密码生成器、自动保存
- **锁定**：点击左下角「锁定」回到解锁页，重新输入主密码才能查看
- **忘记密码**：解锁页「忘记密码？」→ 答对密保问题 → 设置新主密码，数据保留；密保问题解锁后可随时增删（侧栏「密保问题」）
- **备份与迁移**：解锁后侧栏「导出备份」生成单文件加密备份（`.ink`，内为 JSON，含全部笔记与密码条目）；新设备在首次设置页「导入备份」整体迁移（沿用原主密码与密保问题）；已有数据的设备用侧栏「导入备份」合并（同 id 条目较新者胜，**删除不会传播**）
- **语言**：默认英文；标题栏「EN / 中文」按钮中英切换，解锁页即可用，手动切换后自动保存，重启保持

## 数据位置

- 开发模式：项目内 `data/`（`notes.json`、`vault.json` 均加密）
- 打包后：`%APPDATA%/inknote/`

## 说明

- 所有数据由随机 recoveryKey 加密（AES-256-GCM）；主密码与密保答案只是解开它的两把钥匙，密钥只存在于主进程内存
- 密保答案采用独立加盐派生，安全性弱于主密码，请勿设置易猜的答案
- 忘记主密码且未设密保问题、密保答案也答不上，或数据损坏时，解锁页提供「重置密码库」：永久删除全部数据后重新设置主密码
- 所有 JSON 均以「临时文件 + fsync + 原子替换」写入，崩溃/断电不会截断数据文件
- 复制的密码 30 秒后自动从剪贴板清除（若期间复制了其它内容则不打扰）
- 备份文件与 `vault.json` 同等敏感（可离线爆破主密码），请妥善保管；合并导入只合并数据，不改变本机主密码与密保
- 自动保存有 400ms 防抖；锁定或关窗前会自动冲刷挂起的编辑，不会丢最后几笔输入
- 空白笔记（无标题/正文/标签）不会写入磁盘
- Markdown 预览不加载远程图片（CSP 限制，避免笔记内容向外发请求）
- 启动脚本会自动清除 `ELECTRON_RUN_AS_NODE` 环境变量（本机遗留变量会使 Electron 退化为纯 Node）
